# Fieldnote improvements — v1.6.1 (Launch fix + feelable upgrades)

## Why 1.6.1
1.6.0 could fail to open on Android: it linked deprecated `expo-av` (removed from modern Expo SDKs). Replaced with soft-required `expo-audio`, and added a one-time What’s New primer so upgrades are obvious on first open.

## Feel this build
1. **Opens cleanly** after the 1.6.0 launch break
2. **What’s New sheet** on first launch (also More → What’s new in 1.6)
3. **Stronger toolbar grip** — drag to move the tool rail
4. **Updated gesture tips** — double-tap note, working folder, Repair Map
5. **Demo hero copy** points at pan / double-tap / toolbar grip (reset demo to see it)

## Still in 1.6.x
Movable toolbar, side resize, edge-pan drag, double-tap notes, Repair Map, audio/playlist cards, working folders, PDF cover chrome.
